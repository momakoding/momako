# 你的游戏SPEC - Your game SPEC

> 由开发助手根据游戏设计需求编写与迭代

## 当前实现（摘星星 / Picking Stars）

平台跳跃 + 收集星星：`src/scenes/platform-chain.ts` 按跳跃物理生成逐级可达的台阶链，⭐ 悬浮在平台上方一跳可达的空域内；收集完一轮后重启场景重新生成整张地图，分数与已完成轮数保留。

## 未来想法 / Future Ideas

- 使用更好的 PCG（程序化内容生成）算法优化地图生成：当前台阶链是基于跳跃物理约束的随机游走，后续可换更成熟的 PCG 算法（如 WFC 波函数坍缩、规则化图形文法、种子化可复现生成），在保证"每一级都跳得上去"的前提下产出更丰富的地形结构。
