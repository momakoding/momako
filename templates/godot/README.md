# momako-jam-godot

Godot 4.x Game Jam 快速原型脚手架与 itch.io 极速导出预设。

## 特性 (Features)
- **Godot 4.x Compatibility**: 默认兼容 WebGL / HTML5 导出，适配 itch.io。
- **UI & Theme**: 预置与 `@momako-jam/hud` 视觉语言一致的深色像素 UI 主题。
- **Audio Manager**: 全局 BGM / SFX 音量总线单例。
- **Screen Shake & Tween Utilities**: 常见 Game Jam 增强打击感与汁水感（Juiciness）工具脚本。
- **AI Agent 规范**: 附带 `AGENTS.md` 与 GDScript 协作指引。

## 快速上手
1. 使用 Godot 4.3+ 打开本目录中的 `project.godot`。
2. 按 `F5` 即可运行示例关卡。
3. 导出设置已内置 HTML5 预设，直接点击 Project -> Export -> Web 即可上传至 itch.io。
