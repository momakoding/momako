# momako-jam-unity

Unity 6 / 2022+ Game Jam 快速原型模板与 WebGL 响应式模板。

## 特性 (Features)
- **WebGL Responsive Template**: 解决 Unity 默认 WebGL 模板在移动端和不同长宽比显示错位的问题。
- **Input System (New)**: 预配置键盘、手柄统一输入映射。
- **Audio Service**: 支持跨场景淡入淡出的背景音乐管理器。
- **Jam Juiciness Library**: 屏幕震动、慢动作特写（Freeze frame）、飘字特效。
- **AGENTS.md**: 针对 C# 和 Unity 生命周期的 AI 编程约定。

## 快速上手
1. Unity Hub 打开本工程。
2. 打开 `Assets/Scenes/GameScene.unity`。
3. 点击 Play 即可体验。
