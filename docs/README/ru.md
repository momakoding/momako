> В него входят главное меню, общий UI, диалог настроек, сохраняемые настройки звука и разрешения, переключение языка, адаптивный canvas и правила работы с ИИ-агентами.

## Поддерживаемые движки и их стеки технологий

Momako поддерживает несколько движков и фреймворков с единым интерфейсом и общей событийной связью:

| Движок / режим | ID шаблона | Имя пакета | Возможности и сценарии | Технологии |
| --- | --- | --- | --- | --- |
| 🎮 **2D Web** | `er` | `momako-er` | Аркадная физика Phaser 4 и генерация уровней. Также поддерживаются игры на чистом Vue (idle, карточные, текстовые детективы, инкрементальные) и смешанные варианты. | Vue 3 + Phaser 4 / Pure Vue + HUD |
| 🌐 **3D Web** | `san` | `momako-san` | Декларативные 3D-сцены, освещение, меши и следящая камера на TresJS. Подходит для 3D-прототипов. | Vue 3 + TresJS (Three.js) + HUD |
| 🤖 **Godot 4.x** | `godot` | `momako-godot` | Пока не реализовано | Godot 4, GDScript |
| ⚡ **Unity 6** | `unity` | `momako-unity` | Пока не реализовано | Unity 6, C# |
| 🔥 **Unreal 5** | `unreal` | `momako-unreal` | Пока не реализовано | UE5, Blueprints |

### Общие пакеты

* **`@momako/hud`**: UI-библиотека, общая для всех веб-движков. В ней страницы главного меню (`home`), правил игры (`how-to-play`), диалога настроек (`settings`) и титров (`about-us`), игровой контейнер `<GameShellLayout>`, сохранение настроек и игровых данных на базе Pinia и система стилей на Tailwind CSS v4.
* **`@momako/core`**: шина событий без зависимостей и определения событий, работающие во всех движках. Игровое представление и слой интерфейса зависят только от протокола событий, а не друг от друга.

## Быстрый старт: создайте проект игры

> 💡 **Примечание**: этот репозиторий — инструмент для генерации проектов. Клонировать его, чтобы сделать игру, не нужно. Выполните команду в терминале, чтобы создать отдельный проект:

```bash
npx momako create my-game
# or
npm create momako my-game
```

Интерактивный диалог задаёт два вопроса:

1. **Название проекта** (по умолчанию `my-jam-game`)
2. **Целевой движок**:
   * `1) 🎮 2D Web (Vue 3 + Phaser 4 / pure Vue) - [momako-er]`
   * `2) 🌐 3D Web (TresJS / декларативное 3D) - [momako-san]`
   * `3) 🤖 Godot 4.x Engine - [momako-godot]`
   * `4) ⚡ Unity 6 (WebGL/PC) - [momako-unity]`
   * `5) 🔥 Unreal Engine 5 - [momako-unreal]`

Диалог можно пропустить, передав аргументы:

```bash
npx momako create my-2d-game --template er
npx momako create my-3d-game --template san
```

### Разработка в созданном проекте

```bash
cd my-game
pnpm install
pnpm dev
```

В проекте уже настроен собственный Git, есть документ геймплейного дизайна `docs/spec/spec.md`, руководства по разработке в `docs/guide/` и `AGENTS.md` с правилами совместной работы с ИИ, рассчитанными на разработчиков игр.

## Основные принципы

1. **Отрисовка игры отделена от интерфейса**:
   * Canvas или 3D-вьюпорт отвечает только за игру, её физику и ввод игрока.
   * Стартовый экран, управление громкостью и звуком, настройки качества и разрешения, меню паузы и сохранения находятся в `@momako/hud`. Обе стороны общаются только через стандартные определения событий.

2. **Игровой контент может разрастаться на множество страниц**:
   * Шаблоны организуют код по предметным областям. Игровой контент находится в `src/game/`, общий код — в `src/shared/`.
   * Можно добавлять игровые подстраницы: сюжетные тексты, магазин, выбор уровня или инвентарь.

3. **Правила для разработки с помощью ИИ**:
   * Соглашения Momakoding по работе с ИИ подключаются через `AGENTS.md` и `docs/spec/`.
   * Они закрепляют имена компонентов в kebab-case, стиль `@apply` из Tailwind v4, формат Keep a Changelog и этап подтверждения перед коммитами.

## Участие в разработке и поддержка фреймворка

Чтобы добавить шаблон для нового движка, расширить компоненты HUD или поддерживать CLI, клонируйте этот монорепозиторий:

```bash
# 1. Install all workspace dependencies
pnpm install

# 2. Build and check everything in parallel
pnpm -r build

# 3. Check and sync maintainer and template docs
pnpm sync:docs

# 4. Start a dev server
pnpm dev:er      # 2D game development
pnpm dev:san     # 3D game development
pnpm dev:cli     # debug the scaffolding tool
```
